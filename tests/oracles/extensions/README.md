# Independent extension references

`regression.csv` and `walk.csv` are deterministic datasets generated by
`regenerate.py`. `oracle.R` calls R's stats, lmtest, tseries, urca, nortest,
DescTools, pROC, kSamples and survival implementations, or explicitly derives
the statistic using independent R linear algebra/enumeration. It never calls
Meliora, SciPy, statsmodels or arch.

`r_results.csv` includes a statistic for every new public function and p-values
where the R convention matches. `r_session.txt` records R and package versions;
`provenance.json` hashes datasets, generator, R script, results and session.
Missing files or method references are skipped, never labelled verified; stale
hashes fail. The standard tests use the frozen outputs without requiring R.
Hashes normalise CRLF to LF so Git line-ending conversion preserves provenance.

Regenerate from the repository root:

```powershell
python tests/oracles/extensions/regenerate.py
```

Install the named R packages first, either in the default R library or the
workspace's ignored `.r-libs`. The generator records the actual installed
versions rather than claiming compatibility with untested versions.

## Deliberate convention differences

- BDS: tseries uses a different finite-sample correlation sum. Both its raw
  result and an independently pair/triple-enumerated conditional result are
  retained. The latter matches the Kanzler initial-history convention used by
  statsmodels. Equality to tseries's raw statistic is not asserted.
- Phillips-Perron: urca uses current-level centred sums in its adjustment;
  arch uses the lagged-regression coefficient variance. Both raw urca and
  independently calculated R lagged-regression results are retained. P-values
  and critical values use different calibrations and are not equated.
- Shapiro-Wilk: SciPy 1.11's single-precision swilk implementation differs from
  R by about 2.36e-6 in the example p-value. Only this old-backend p-value check
  has a documented 3e-6 absolute precision allowance. Modern SciPy agrees at
  the ordinary tolerance. The statistic is checked separately at tight tolerance.
- kSamples rounds standardised AD statistics to five significant figures.
  The assertion compares exactly that rounded precision. Its p-value algorithm
  is not equated to SciPy's bounded table interpolation.
- Fisher: R reports a conditional odds-ratio MLE; the API reports the sample
  cross-product ratio. The oracle computes that ratio explicitly and uses R's
  exact conditional p-value.
- Wilcoxon: R reports W+ while the two-sided API reports min(W+, W-); the
  independently known total rank sum supplies the conversion.
- Johansen: the reference solves the detrended canonical-correlation problem
  explicitly in R to match the supported statsmodels deterministic convention.
  Its trace statistic is checked; separate tests check trace/max-eigenvalue
  identities. Critical values are backend tables, not fabricated p-values.
- Stochastic inference: R checks the observed DW and sup-F statistics. Seeded
  reproducibility, endpoint exclusions and search-adjusted calibration are
  tested separately; random draws from different languages are not equated.

Small independent arithmetic cases live in the numerical test files. Optional
backends are supplemented by manual ADF regressions, KPSS partial sums,
fitted-normal AD CDF sums and cointegrating residual regressions. This avoids
using a wrapper's own backend as its only numerical oracle.

# Historical research notebooks

These notebooks preserve exploratory work; they are **not supported package examples or numerical certification evidence**.

- `ranking_capital_requirements.ipynb`: capital-requirement research, formerly at repository root.
- `legacy_r_benchmarks.ipynb`: historical R comparisons with saved outputs and external R package/data dependencies. It has not been rerun in the current validation environment and may require path/package repairs.

The complete, supported Python examples are in [../examples.ipynb](../examples.ipynb). They are self-contained and executed in CI. Research notebooks are excluded from source distributions and wheel builds; Git history preserves their original location and contents.
